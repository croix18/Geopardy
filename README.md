# Geopardy

**Geopardy!** is a classroom review game on a quiz-show board, run like a trivia night: every team
answers every question on a whiteboard, and scores only go up. This repository holds the game engine,
the units (question sets) written for it, and the built games.

## Play

Download a file from [`games/`](games/) and open it in Chrome. Each game is one self-contained HTML
file that makes no network requests, so it runs from a Google Drive folder or a USB stick.

| Game | Class | Content |
|---|---|---|
| `Geopardy_Exponent_Laws.html` | Grade 7 Accelerated | Product, quotient and power rules, zero and negative exponents, missing exponents |
| `Geopardy_Area_of_Polygons.html` | Grade 7 | Area of rectangles, triangles, parallelograms, trapezoids, rhombi and composite figures, with a drawn figure on every question |

Both are 5 categories by 5 point values (100 to 500) plus a 1000-point Final Question.

## How a question runs

1. The picking team chooses a category. Each category is a ladder: its tiles open in order from the
   lowest value, so the questions get harder as the points rise.
2. **Solo, silent.** Everyone works alone while the timer and music run (0:30 at 100 up to 1:30 at 500).
3. **Huddle.** Teams agree on an answer. The board names which player writes it.
4. **Boards up.** Reveal the answer and the worked step, tap every team that got it right, award points.

One tile per game is a hidden Double Up. The setup screen reads the bell schedule, estimates how many
questions fit before the bell, and the game calls the Final with six minutes left. The menu prints a
student recording sheet and an answer key.

## Build

```sh
python3 tools/build.py                              # every unit in units/ -> games/
python3 tools/build.py units/area_of_polygons.json  # one unit
```

Python 3 only; no packages needed to build. The build includes the files in `engine/` verbatim and
embeds the unit, so the same inputs always produce the same bytes.

## Write a unit

A unit is one JSON file in `units/`. `units/_placeholder.json` is a small sample.

```json
{
  "title": "Laws of Exponents",
  "course": "Grade 7 Accelerated Math",
  "tiers": [100, 200, 300, 400, 500],
  "tierNotes": ["Warm-up", "One twist", "Variables", "Multi-step", "Challenge"],
  "categories": [
    { "name": "Product of Powers",
      "questions": [
        { "q": "Write as a single power.\n$$5^{3} \\cdot 5^{4}$$",
          "a": "$5^{7}$",
          "work": "Same base, so add the exponents: $3 + 4 = 7$." }
      ] }
  ],
  "final": { "category": "Every Law at Once", "solo": 90, "q": "...", "a": "...", "work": "..." }
}
```

- Each category needs exactly one question per tier, easiest first. Up to five tiers.
- `$...$` is inline math, `$$...$$` is display math, `\$` is a dollar sign. A newline in `q` is a line break.
- `work` is the one-line explanation shown under the answer and printed in the key.
- `fig` (optional) is an inline SVG shown under the question; `afig` (optional) replaces it on the answer
  screen and in the printed key, for example to show how a composite figure splits.
- `final.solo` (optional) is the Final's solo time in seconds; the default is 60.

The two real units are generated by scripts in `units/src/` that check their own answers before they
write anything: the exponent answers with a computer algebra system, the area answers by recomputing
each area from the coordinates the figure is drawn from. Prefer that to typing answers by hand.

## Check

```sh
tools/check.sh
```

Regenerates the units, rebuilds the games, and plays each one start to finish in headless Chromium at
panel, laptop and phone sizes. It needs `pip install playwright sympy` and a Chromium that Playwright
can launch. Screenshots of every question and PDFs of the printed pages land in `out/`.

## Layout

```
engine/          the game, in parts
  index.html       the page shell with include markers
  game.js          rules, screens, timers, printing
  style.css        the look
  quizmusic.js     synthesized stings (also runs in a worker)
  schedule.json    bell schedule for the bell guard
  audio/           Mozart cues (mp3)
  vendor/          KaTeX and the embedded fonts
units/           one JSON file per unit; src/ holds the generators
games/           built single-file games
tools/           build, tests, push
docs/HANDOFF.md  project notes: constraints, design rules, what is and is not verified
```
